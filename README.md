# Hjson

**Hjson** — это Human JSON: расширение JSON, ориентированное на людей. Тот же JSON, но с комментариями, без обязательных кавычек у ключей, без запятых, с multiline-строками и терпимостью к мелочам вроде висячих запятых. Парсится в обычные JS-значения, сериализуется обратно в Hjson.

Этот пакет — **парсер и стрингфаер Hjson** с опциональной возможностью подключить Vite-плагин для импорта `.hjson` файлов прямо в сборку.

## Зачем Hjson

- **Конфиги, которые читает человек.** JSON для машин, Hjson для людей: комментарии, свобода форматирования, никаких лишних кавычек и запятых.
- **Обратная совместимость с JSON.** Любой валидный JSON — валидный Hjson.
- **Комментарии.** `#`, `//`, `/* */` — сохраняются через `keepWsc` и доступны через `getComment()`.
- **Multiline-строки.** `'''...'''` для длинных текстов без экранирования.
- **Quoteless-строки.** Значения можно писать без кавычек, включая кастомные форматы через `dsf`.

## Базовое использование

```js
import { parse, stringify } from 'hjson'

const data = parse(`
  # комментарий
  name: hjson
  version: 3.0
  features: [
    human-friendly
    json-compatible
  ]
`)

const text = stringify(data, { space: 2, quotes: 'min' })
```

## API

### `parse(source, opt)`

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `keepWsc` | `boolean` | `false` | Сохранять комментарии и whitespace (WSC). Доступны через `getComment()`. |
| `dsf` | `object \| null` | `null` | Domain Specific Formats — кастомные форматы, распознаваемые в quoteless-строках. |

### `stringify(data, opt)`

#### Форматирование

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `eol` | `'\n' \| '\r\n'` | `EOL` | Символ конца строки. |
| `space` | `number \| string` | `'  '` | Отступ: число пробелов или готовая строка. |
| `bracesSameLine` | `boolean` | `false` | Открывающая `{`/`[`/`'''` на одной строке с ключом. |
| `emitRootBraces` | `boolean` | `true` | Оборачивать корневой объект в `{}`. Если `false` — скобки убираются. |
| `separator` | `boolean` | `false` | Добавлять запятые между элементами. Побочно включает `quoteStrings`. |
| `multiline` | `'std' \| 'no-tabs' \| 'off'` | `'std'` | Режим multiline-строк (`'''`): `std` — табы разрешены; `no-tabs` — табы экранируются; `off` — multiline отключён. |
| `condense` | `number` | `0` | Порог схлопывания объекта/массива в одну строку. `0` — выключено. |

#### Кавычки

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `quotes` | `'min' \| 'keys' \| 'strings' \| 'all'` | `'min'` | Режим кавычек (см. таблицу ниже). |
| `quoteChar` | `'"' \| "'"` | `'"'` | Символ кавычек. |

#### Комментарии и порядок

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `keepWsc` | `boolean` | `false` | Сохранять комментарии/whitespace при сериализации (из `getComment(data)`). |
| `sortProps` | `boolean` | `false` | Сортировать ключи объекта по алфавиту. |
| `dsf` | `object \| null` | `null` | Domain Specific Formats — кастомные форматы для значений. |

#### Прочее

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `colors` | `boolean` | `false` | ANSI-раскраска вывода (для терминала). |

### Режимы `quotes`

| Режим | Ключи | Строки | Комментарий |
|-------|-------|--------|-------------|
| `'min'` (дефолт) | кавычки только если обязательны | кавычки только если обязательны | минимально возможное число кавычек |
| `'keys'` | все в кавычках | только если обязательны | |
| `'strings'` | только если обязательны | все в кавычках | |
| `'all'` | все в кавычках | все в кавычках | |

## Vite-плагин (опционально)

Плагин позволяет импортировать `.hjson` файлы напрямую в Vite-сборку. Это **дополнение** к парсеру, а не его замена: сам Hjson-функционал живёт в `parse`/`stringify`, плагин лишь встраивает чтение `.hjson` в бандлер с query-параметрами для трансформации.

### Подключение

```js
import hjson from './vite-plugin-hjson.js'

export default {
    plugins: [
        hjson({
            handlers: {
                // именованные обработчики
            },
            default: null, // имя handler'а по умолчанию
        }),
    ],
}
```

### Использование

```js
import data from './file.hjson'
import config from './file.hjson?as=config'
import picked from './file.hjson?pick=a.b,c.d'
import omitted from './file.hjson?omit=a.b,c.d'
import combined from './file.hjson?as=config&pick=a.b,c&omit=d'
```

### Query-параметры

| Параметр | Описание |
|----------|----------|
| `as=<name>` | Применить handler с указанным именем из `options.handlers`. |
| `pick=a.b,c.d` | Оставить только указанные пути. Один путь — вернуть значение, несколько — объект `{ "a.b": ..., "c.d": ... }`. |
| `omit=a.b,c.d` | Исключить указанные пути (глубокая копия без мутации оригинала). |

Порядок применения: `as` → `pick` → `omit`.

### Опции плагина

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `handlers` | `Record<string, Function>` | `{}` | Именованные обработчики значения до применения `pick`/`omit`. Сигнатура: `(value, params, { file, ctx }) => any`. |
| `default` | `string \| null` | `null` | Имя handler'а по умолчанию, если в import не указан `?as=...`. |
| `dts` | `boolean` | `true` | Генерировать типы для импортов `.hjson` (см. ниже). |

### Типы для TypeScript

Рядом с каждым `file.hjson` плагин пишет `file.d.hjson.ts` с типом значения, которое даёт импорт **без query** (с учётом `default`-handler'а):

```ts
// config.d.hjson.ts — сгенерировано
declare const value: {
    server: {
        host: string
        port: number
    }
}
export default value
```

Чтобы TypeScript находил такие файлы, в `tsconfig.json` нужно включить:

```json
{ "compilerOptions": { "allowArbitraryExtensions": true } }
```

Объявления обновляются при старте сборки и dev-сервера (сканируется корень проекта, кроме `node_modules`, `.git` и `outDir`), при каждом импорте и при изменении `.hjson` в dev-режиме. Типы расширяются как у JSON-импортов: `'a'` → `string`. Объекты в массивах сливаются, ключи, которые есть не у всех элементов, становятся необязательными.

Импорты с query (`?pick=`, `?as=`, `?omit=`) так не типизируются: TypeScript не умеет сопоставить модулю с query отдельный файл объявления. Для них по-прежнему нужно `declare module '*.hjson?*'` или явное приведение типа.

### Обработка ошибок

- Неизвестный handler — `this.error('[hjson] unknown handler "..." in <file>')`.
- Путь не найден при `pick` — `this.error('[hjson] path "..." not found in <file>')`.

### Ограничения плагина

- Значения сериализуются через `JSON.stringify`, поэтому функции, `undefined`, `Symbol`, `BigInt` и циклические ссылки не поддерживаются.
- `omit` делает глубокую копию через `JSON.parse(JSON.stringify(...))` — теряются типы, не представимые в JSON.
- Плагин читает файл синхронно (`fs.readFileSync`).
- `enforce: 'pre'` — обработка `.hjson` происходит раньше других плагинов Vite.
